# Respect Bank

Бот, который превращает респект в цифры.

## Как это работает
- даёшь +100 → человек получает очки
- ставишь реакции → влияет на баланс
- есть рейтинг

## Зачем это нужно
- геймификация чатов
- прозрачная репутация
- фан
